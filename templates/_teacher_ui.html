{# Phase 4A shared teacher UI: one dropdown design, clear-search controls and the "generating…" state of AI generation forms. Included once by dashboard_base.html, so every teacher page gets the same behaviour. Dropdowns. Browsers draw the open list of a native stays in the form, hidden, and remains the single source of truth: it is what gets submitted, what `required` validates, and what existing page scripts read and listen to (`change` is dispatched on it). Without JavaScript the native select is used, with the same option colours where the browser allows it. Opt out per element with `data-native-select`; `multiple` selects are left native. #}
